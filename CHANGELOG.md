## [0.0.1] - 2026-11-27

### Added

- Initial `oh-my-coding` Agent Skill with `design`, `review`, and `principle`
  modes and a four-step workflow.
- Seven-principle, shape-neutral API design philosophy (`references/api-design/philosophy.md`).
- API design reference layer contract and subcategory index
  (`references/api-design/README.md`).
- Google BigQuery API design case-study subcategory with principle mapping and
  an explicit "borrow philosophy, never the shape" exclusion list
  (`references/api-design/google-bigquery-api-design.md`).
- Claude plugin marketplace manifest, README, Makefile, and license.
